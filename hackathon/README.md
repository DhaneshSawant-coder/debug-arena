# Debug Arena

1. Install Node.js 18+.
2. In this folder run:  npm install
3. Start:  ADMIN_PASSWORD=yourpassword node server.js   (Windows PowerShell: $env:ADMIN_PASSWORD="yourpassword"; node server.js)
4. Open http://localhost:3000  (admin: "Admin" tab, participants: name + access code)

Optional: SLOT_MINUTES=20 (default), PORT=3000.
Participants on other devices need your computer's network address, or deploy to a host such as Render or Railway.
